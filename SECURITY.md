# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on
this repository (Security tab). Please do not open a public issue for it.

In scope: this app, and how it uses the Aitherium sign-in and API. Especially welcome:
any way a private profile, a private room or another member's data shows in the app;
any way a token leaves the tab or reaches a host other than the configured API and IdP.
